## 三档线路差在哪：延迟数字要按档位对号入座

延迟按档位分开看。Pro 到大陆 10–50ms，EB 居中，T1 移动 50ms 出头、联通绕日本、电信可能超过 200ms。

Pro 的实测口径最统一，香港到大陆普遍在 10–50ms，广州、上海可以压到 30ms 以内，移动偶尔出现个位数。晚高峰掉速不明显，这才是它敢卖 $39.90 却只给 500GB 流量的原因。

EB 走三网 CMI，大陆访问比 T1 稳，又不如 Pro 那么极致。移动用户体验接近 Pro，电信稍弱一档，适合主要用户在移动、联通两家的场景。

T1 的表现分运营商。移动经 CMI 直连香港 NTT，延迟 50ms 出头，落地体验不错；联通去程绕日本 NTT，回程还行；电信最差，路由可能绕新加坡再进香港，延迟普遍超过 200ms，丢包也更高。它的正确用法是国际建站、API 节点、CDN 边缘，或者配广移、IPLC 之类的中转来用。

网上常见的 “DMIT 香港延迟 39ms”“10–50ms 基本不丢包”，说的是 Pro 档。把这组数字套到 $6.90 的 T1 上，会得出完全相反的判断。

## FAQ

**Q：DMIT 香港 Lite 还在卖吗？**

A：官网搜不到 “Lite” 这个字样了。有整理称原 Lite 系列已改名为 Tier 1（T1），线路定位和价格基本延续，入门 TINY 月付 $6.90。这条改名说法来自第三方整理，官网没有对应公告，但从定位和价格看，T1 承接的就是原来那个位置。

**Q：香港 T1 能解锁 Netflix 吗？**

A：T1 是香港原生 IP，第三方实测能解锁 Netflix 港区，TVB 之类平台表现一般。商家对解锁不做保证，平台策略变化也不在控制范围内。

**Q：电信用户能不能用香港 T1？**

A：直连不合适。T1 不对电信做优化，路由可能绕新加坡，延迟超过 200ms 且丢包更高。有广移、IPLC 这类中转可以用，纯直连选 EB 或 Pro。

**Q：流量用超了会停机吗？**

A：不会，超量后限速继续跑，具体限到多少以套餐规格为准。

**Q：香港 T1 和洛杉矶 T1 有什么区别？**

A：价格和配置基本相同，区别在机房位置。香港到亚太各地延迟更低，洛杉矶对欧美更友好。核心用户在亚太选香港，纯海外业务两边都可以。

**Q：续费会涨价吗？**

A：用 RECURRING 结尾的循环码，续费同价；不挂码按官网当时原价续费。买之前确认码的类型，别把首年折扣当成长期价。
